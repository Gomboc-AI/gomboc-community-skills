# Add Metadata to an ORL Rule

Load and execute **`gomboc_community_task_enrich_rule`**.

## Example Usage

```
/gomboc-community:add-metadata ./rules/ensure_s3_bucket_encryption_enabled
/gomboc-community:add-metadata Update gomboc-ai/terraform/aws/rds-deletion-protection
```
